# Dragostina - Alternative End

Para permitir a la gente sedienta de loot seguir peleando sin molestar a la gente rara que le gusta construir se le ha otorgado la habilidad de “Espacio Dimensional” a Dragostina, donde cuando esta haya muerto en el END permitirá mediante un comando enviar a un nuevo END diseñado para pelear eternamente con Dragostina.

El comando se debe usar en el portal de salida del END y es `/dragostina unirse`

Pero.. no todo es bonito.. sí hay una pelea en el END alternativo deberás pagar tributo para poder participar el cual son Ojos de Ender.

Si en dicha pelea el grupo decide rendirse Dragostina desaparecera.

{% hint style="info" %}
Al finalizar una pelea el mundo entrara en estado de reinicio.
{% endhint %}
